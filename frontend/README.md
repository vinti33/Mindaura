# 🎨 Mind Aura — Frontend Web Application

React 19 single-page application for the **Mind Aura** mental wellness app.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up `.env` (refer to `.env.example`):
   ```env
   REACT_APP_API_URL=http://localhost:5000
   ```

3. Start development server:
   ```bash
   npm start
   ```

Refer to the main [Root README](../README.md) for full application documentation.
