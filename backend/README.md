# ⚙️ Mind Aura — Backend API Service

Express 5 Node.js API backend for the **Mind Aura** application.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up `.env` (refer to `.env.example`):
   ```env
   GEMINI_API_KEY=your_key
   MONGO_URI=your_mongodb_uri
   JWT_SECRET=your_secret
   FRONTEND_URL=http://localhost:3000
   PORT=5000
   ```

3. Run the server:
   ```bash
   node server.js
   ```

Refer to the main [Root README](../README.md) for full documentation.
